# Anteraja Capstone Project

Project ini dibuat sebagai tempat pengembangan Shipment Tracking Widget untuk ekosistem Anteraja.
Fokus utamanya adalah bikin fitur pelacakan resi secara real-time dan nampilin riwayat pengiriman paket dengan lebih informatif.
Repository ini disiapin sebagai fondasi awal yang rapi dan aman sebelum masuk ke tahap integrasi fitur AI berikutnya.
